# 118. Pascal's Triangle

[![LeetCode](https://img.shields.io/badge/LeetCode-118-FFA116?logo=leetcode&logoColor=white)](https://leetcode.com/problems/pascals-triangle/description/)
![Difficulty: Easy](https://img.shields.io/badge/Difficulty-Easy-00b8a3)

Given an integer `numRows`, return the first `numRows` of Pascal's triangle.

In Pascal's triangle, each number is the sum of the two numbers directly above it.

## Example 1

```text
Input: numRows = 5
Output: [[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

## Example 2

```text
Input: numRows = 1
Output: [[1]]
```

## Constraints

- `1 <= numRows <= 30`
