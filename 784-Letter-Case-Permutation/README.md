# 784. Letter Case Permutation

[![LeetCode](https://img.shields.io/badge/LeetCode-784-FFA116?logo=leetcode&logoColor=white)](https://leetcode.com/problems/letter-case-permutation/description/)
![Difficulty: Medium](https://img.shields.io/badge/Difficulty-Medium-ffc01e)

Given a string `s`, transform every letter individually to lowercase or uppercase to create another string. Return all possible strings that can be created in any order.

## Example 1

```text
Input: s = "a1b2"
Output: ["a1b2","a1B2","A1b2","A1B2"]
```

## Example 2

```text
Input: s = "3z4"
Output: ["3z4","3Z4"]
```

## Constraints

- `1 <= s.length <= 12`
- `s` consists of lowercase English letters, uppercase English letters, and digits
