# 448. Find All Numbers Disappeared in an Array

[![LeetCode](https://img.shields.io/badge/LeetCode-448-FFA116?logo=leetcode&logoColor=white)](https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/description/)
![Difficulty: Easy](https://img.shields.io/badge/Difficulty-Easy-00b8a3)

Given an array `nums` of `n` integers in the range `[1, n]`, return all integers in that range that do not appear in `nums`.

## Example 1

```text
Input: nums = [4,3,2,7,8,2,3,1]
Output: [5,6]
```

## Example 2

```text
Input: nums = [1,1]
Output: [2]
```

## Constraints

- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`

**Follow up:** Can you solve it without extra space in `O(n)` runtime? The returned list does not count as extra space.
