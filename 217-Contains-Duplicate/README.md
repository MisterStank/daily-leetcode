# 217. Contains Duplicate

[![LeetCode](https://img.shields.io/badge/LeetCode-217-FFA116?logo=leetcode&logoColor=white)](https://leetcode.com/problems/contains-duplicate/description/)
![Difficulty: Easy](https://img.shields.io/badge/Difficulty-Easy-00b8a3)

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

## Example 1

```text
Input: nums = [1,2,3,1]
Output: true
```

**Explanation:** The element `1` occurs at indices `0` and `3`.

## Example 2

```text
Input: nums = [1,2,3,4]
Output: false
```

**Explanation:** All elements are distinct.

## Example 3

```text
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
